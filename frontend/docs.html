Candidate Verification System: Platform & Workflow Guide

Candidate Verification System (CVS) is an enterprise-grade platform uniting high-volume applicant intake, automated background screening, anomaly detection, and accountable human compliance review sign-offs.

01 // PROCESS LIFECYCLE

How The Verification Pipeline Works

5 Sequential Stages
01 Intake

Candidate Onboarding

Recruiters or Admins register applicant profiles manually or execute high-volume CSV batch uploads (up to 10,000+ rows). The system sanitizes names, synthesizes missing applicant emails, validates phone numbers, and registers isolated candidate dossiers.

Action: Add Profile / Import CSV
02 Extraction

Resume Ingestion & Parsing

Upload resume files (PDF, DOCX, TXT). The extraction engine parses text content, identifies contact details, work history, and job titles, and computes a cryptographic SHA-256 checksum to ensure tamper prevention.

Action: Upload Resume / Extract Text
03 Automated Checks

Automated Screening

The automated screening rules engine cross-examines candidate claims against resume contents. It flags employment timeline gaps, qualification mismatches, and compliance discrepancies, calculating an automated verification score.

Action: Run Automated Verification
04 Compliance Queue

Reviewer Sign-off

Verifications requiring human sign-off are routed to certified Compliance Reviewers. Reviewers inspect candidate dossiers side-by-side with original resume evidence, evaluate flagged issues, and issue binding decisions: Approved, Rejected, or Needs Info.

Action: Submit Audit Decision
05 Audit Trail

Immutable Audit Trail & Regulatory Governance

Every state transition, automated check outcome, reviewer decision, and document view is permanently logged into the immutable audit repository with chronological timestamps, operator identities, and cryptographic checksums. This provides defensible, audit-ready compliance reporting.

Result: Audit-Ready Compliance Certificate & Chronological History

03 // OPERATIONAL WORKFLOWS

Step-by-Step Task Procedures

Standard Procedures

1. How to Add a Candidate and Run Automated Verification

Navigate to the Candidates Directory. Click Add Candidate in the top-right corner to open the candidate intake form. Fill in the candidate's first name, last name, email, job title, and country, then click Create Candidate. Once the candidate row appears, click the Verify button on the candidate's row or open the Dossier to run the automated screening engine.

2. How to Upload and Inspect Resumes

From the candidate directory, click Dossier on any candidate to access their detailed verification profile. Under the Extracted Resume Evidence tab, you can drag and drop or select a resume file (PDF, DOCX, or TXT). Once uploaded, the extracted resume text is displayed alongside the candidate information, and you can download the original file at any time.

3. How to Assign and Complete a Compliance Review

In the candidate dossier, the Reviewer Assignment card allows an Administrator to assign the verification case to a certified compliance specialist (such as Sarah Jenkins). When Sarah logs in or switches to the Reviewer session, the case appears in her Assigned Reviewer Queue. Clicking Evaluate opens the evaluation view where the reviewer selects Approve (Passed), Reject (Failed), or Needs Info with justification notes to finalize the sign-off.

4. How to Switch Roles and Test Permissions

The application supports instant session switching between test roles. In the bottom-left sidebar or top-right header, use the Admin, Recruiter, or Reviewer buttons to immediately switch your active session role and verify that role-based permissions and queue access operate as expected.
